# Sahil Sanghvi @ UVic

An index of coursework from my B.Sc. Computer Science (Software Systems) at the
University of Victoria — one repository per course, each with its own README
documenting every assignment/lab in it. This repo is just the map; the code lives in
the linked repos below.

## Year 1

| Course | Repo | What's in it |
|---|---|---|
| CSC 110 — Fundamentals of Programming I | [`python-fundamentals`](https://github.com/sahil-sanghvi/python-fundamentals) | 10 labs + 10 assignments in Python — variables through file I/O and an intro to classes. |
| CSC 115 — Fundamentals of Programming II | [`java-data-structures`](https://github.com/sahil-sanghvi/java-data-structures) | 6 labs + 9 assignments in Java — ADTs from linked lists through BSTs, hash maps, and heaps. |
| CSC 130 — Introduction to Web Technologies | [`web-dev-fundamentals`](https://github.com/sahil-sanghvi/web-dev-fundamentals) | 2 projects + 4 labs in HTML/CSS/JavaScript. |
| CSC 106 — Fundamentals of Computer Science II | [`olympics-sql-analytics`](https://github.com/sahil-sanghvi/olympics-sql-analytics) | A SQLite exercise over an Olympics database. |
| STAT 123 — Applied Statistics for Computer Science | [`statistical-computing-r`](https://github.com/sahil-sanghvi/statistical-computing-r) | 4 assignments + 10 labs in R Markdown — sampling, wrangling, hypothesis testing, regression. |

## About the Academic Integrity notices

Every repo above carries the same notice: it's published for portfolio and
educational purposes, and using it to complete your own coursework at UVic or
elsewhere would be an Academic Integrity violation. Don't do that — use it to see
how a real problem got solved, not to skip solving your own.
